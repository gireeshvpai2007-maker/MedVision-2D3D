# Source Code

This directory contains the implementation of the MedVision-2D3D research pipeline.

## Planned Modules

- `preprocessing/` — video and image preprocessing
- `models/` — AI models for knee landmark detection
- `tracking/` — temporal landmark tracking
- `evaluation/` — model and pipeline evaluation
- `visualization/` — landmark and tracking visualization

The implementation will be developed incrementally as the dataset and annotation format are finalized.
